## ✨ Features

### 📚 Library & Discovery
- Browse everything on your device by **song**, **album**, and **artist**
- Find any track in seconds with **instant search**
- Save the songs you love to **Favorites** with a single tap

### 🎶 Playlists, Your Way
- Build **custom playlists** for every mood and moment
- Let **smart playlists** — like *Recently Played* — keep themselves up to date

### 🎧 Effortless Listening
- Keep the music playing with **background playback**
- Skip, pause, and replay right from the **home-screen widget**
- Shape your sound with the built-in **equalizer**
- Drift off while the music fades with the **sleep timer**

### 🎨 Make It Yours
- Choose from **multiple player layouts**, including the vinyl-inspired design
- Personalize the look with **themes** and **accent colors**

## 🚀 Getting Started

### Prerequisites

| Requirement | Details |
|---|---|
| **Android Studio** | Latest stable release |
| **JDK** | Version 17 |
| **Device or emulator** | Android 8.0 (API 26) or later |

### Run it locally

1. **Clone** the repository and open it in Android Studio.
2. **Sync** — allow Gradle to resolve all dependencies.
3. **Run** the `app` configuration on your device or emulator.

<details>
<summary><strong>📱 Prefer the terminal? Build a debug APK (Windows)</strong></summary>
<br>

Run this from the project root:

```powershell
.\gradlew.bat assembleDebug
```

Your freshly built APK will be waiting in `app/build/outputs/apk/debug/`.

</details>
